## Sobre mí

Soy desarrollador de software y estudiante de Ingeniería de Software en el **Instituto Tecnológico de las Américas (ITLA)**. Me interesa construir productos útiles de principio a fin: desde el análisis de necesidades y el diseño de la arquitectura hasta la implementación, las pruebas y la puesta en funcionamiento.

He participado en el desarrollo de soluciones empresariales con **Microsoft Dynamics 365**, además de trabajar en proyectos personales y colaborativos que involucran aplicaciones web, herramientas de escritorio, APIs, persistencia de datos y procesos automatizados.

No me limito a una tecnología concreta: elijo herramientas según el problema, con especial atención a la **mantenibilidad, la claridad del código y la evolución del producto**.

## Proyectos destacados

### LapRadar · Seguimiento y análisis de precios

**Proyecto personal · Repositorio privado**  
**Tecnologías:** Python · JavaScript · PostgreSQL/Supabase · Cloudflare Workers · GitHub Actions

Sistema de seguimiento de productos con consultas automatizadas, histórico de precios y alertas. Incluye reglas para evaluar los datos observados y una interfaz para consultar productos, actividad y evolución de precios.

**Aspectos técnicos:** automatización de tareas, integración entre servicios, persistencia, autenticación y pruebas automatizadas.

### Zaiko · Gestión inteligente de inventarios y demanda

**Proyecto colaborativo · Equipo liderado por CEJASS**  
**Tecnologías:** React · TypeScript · Node.js · PostgreSQL · Python

Participación transversal en el desarrollo de una plataforma orientada al control de inventarios, movimientos, análisis de demanda e informes. He contribuido a distintas áreas del proyecto, trabajando con la integración de módulos y la lógica de la aplicación.

**En evolución:** el diseño del sistema contempla un asistente basado en un **LLM local** para facilitar consultas y análisis en lenguaje natural. **Esta integración está planificada; no se presenta como implementada.**

### [Gestor de Tracks](https://github.com/Hirokinng/gestor-de-tracks) · Biblioteca de producción musical

**Proyecto personal · Código público**  
**Tecnologías:** Electron · JavaScript · Express · SQLite

Aplicación de escritorio para Windows destinada a organizar sesiones musicales, asociar archivos de audio, registrar el estado de producción y consultar una biblioteca local sin depender de una conexión permanente a internet.

**Aspectos técnicos:** interfaz de escritorio, API local, persistencia de datos, pruebas y distribución mediante instalador.

[Ver código y versiones](https://github.com/Hirokinng/gestor-de-tracks) · [Releases](https://github.com/Hirokinng/gestor-de-tracks/releases)

## Cómo me gusta desarrollar

- **Entender el problema antes de programar:** priorizar requisitos, casos de uso y reglas del negocio.
- **Diseñar para evolucionar:** separar responsabilidades y facilitar cambios sin comprometer otros módulos.
- **Validar con pruebas:** cubrir comportamientos importantes y comprobar integraciones cuando es posible.
- **Trabajar en equipo:** participar en distintas capas del sistema, revisar decisiones y documentar lo necesario para colaborar mejor.
